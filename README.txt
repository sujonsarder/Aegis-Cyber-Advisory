PUBLISHING ON GOOGLE SITES
  Google Sites cannot import a zip. Either:
  a) Create pages in Google Sites matching the page names and copy the text/tables in; or
  b) Use Insert > Embed > Embed code on each page and paste the page's HTML
     (replace the <link> to style.css with the CSS pasted inside a <style> tag), or
  c) Host this folder (GitHub Pages / Netlify) and embed the URL via Insert > Embed > By URL.
  Submit the Google Sites link through Google Classroom.
